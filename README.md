# 📝 Keeper App

A clean and responsive **note-taking application built with React**. Users can create and delete notes through a simple component-based interface.

## 🔗 Live Demo

**[View Live Demo](https://keeper-app-rpm8.onrender.com/)**

## ✨ Features

* Create notes with title and content
* Delete notes
* Expandable note creation area
* Responsive interface
* Material-UI icons
* Bootstrap styling

## 🛠️ Tech Stack

* React
* JavaScript (ES6+)
* Material-UI
* Bootstrap
* HTML5
* CSS3

## 📂 Project Structure

```text
src/

│   ├── Header.jsx

```

## 🚀 Getting Started

### Clone the repository

```bash
git clone <your-repository-url>
cd keeper-app
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

## 📌 Project Notes

Notes are currently stored in React state, so they are reset when the page is refreshed.
