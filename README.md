
# 📝 Keeper App

A clean and responsive **note-taking application built with React**. Users can create, search, and delete notes through a simple component-based interface, with notes persisted using browser Local Storage.

## 🔗 Live Demo

[**View Live Demo**](https://keeper-app-rpm8.onrender.com/)

## ✨ Features

- Create notes with title and content
- Delete notes
- Search notes by title
- Expandable note creation area
- Persistent notes using Local Storage
- Responsive interface for desktop, tablet, and mobile
- Material-UI icons
- Bootstrap styling

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- Material-UI
- Bootstrap
- HTML5
- CSS3
- Browser Local Storage

## 🚀 Getting Started

### Clone the repository

```bash
git clone <your-repository-url>
cd keeper-app
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

## 📌 Project Notes

Notes are stored in the browser using **Local Storage**, so they remain available after refreshing or reopening the application on the same browser and origin.

The search functionality allows users to quickly find notes by matching their titles.
